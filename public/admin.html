تصدير قالب تعبئة بيانات التقارير

تم إعداد القالب متضمناً كافة أسماء الحقول الرسمية وأنواع البيانات المقبولة بدقة لتفادي أي تعارض عند استيراد البيانات. اختر الصيغة المناسبة لك:

📗
قالب إكسل (Excel / CSV)
جاهز للتعبئة المباشرة ببرامج Microsoft Excel مع صفوف نموذجية وترميز سليم بالكامل.
📄
قالب مهيكل (JSON)
مجهّز بالبنية البرمجية الصريحة مع دليل شرح نوع وقيمة كل حقل لتفادي أي التباس.
📌 أسماء الحقول والأنواع المعتمدة في النظام:
• رقم التقرير: نص / رقم فريد (مثال: 1001)
• موضوع التقرير: نص عنوان التقرير (مطلوب)
• الجهة المستهدفة: نص الجهة أو الشخص المعني
• تاريخ التقرير: تاريخ بصيغة YYYY-MM-DD
• وقت التقرير: وقت بصيغة HH:MM (مثال: 10:30)
• الموقع: مكان أو موقع الحدث الميداني
• تفاصيل التقرير: النص التفصيلي الكامل للبيان
• التقييم: عادي / هام / سري / عاجل
• اسم المدخل: اسم الموظف محرر التقرير
