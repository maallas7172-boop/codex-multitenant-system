## 🌟 مميزات الإصدار المتعدد (Multi-Tenant)
1. **عزل كامل ومستقل لكل جهة أو مؤسسة (100% Data Isolation)**:
   - كل جهة لها رمز تعريفي فريد (`orgCode`).
   - مستخدمو وتقارير ومهام وأجهزة كل جهة معزولة تماماً في قاعدة البيانات.
2. **لوحة الإدارة العليا (Super Admin Dashboard)**:
   - مخصصة لشركة كودكس للبرمجيات (`super_admin.html`).
   - إنشاء جهات ومؤسسات جديدة بضغطة زر واحدة وتوليد حسابات مدراء الجهات تلقائياً.
   - التحكم بحالة اشتراك الجهة (تفعيل / تجميد / تعديل / حذف).
   - إحصائيات حية شاملة لكافة المؤسسات والتقارير والمستخدمين.
3. **تسجيل دخول ذكي للمستخدمين والمدراء**:
   - واجهة دخول تفاعلية تتعرف تلقائياً على رمز الجهة وتحفظه في جهاز المستخدم.
   - فحص استباقي لاستيقاظ السيرفر السحابي (Pre-warm Wakeup).
4. **أمان معتمد للأجهزة الميدانية والهواتف**:
   - ربط الهواتف واعتمادها لكل جهة على حدة.
5. **جلسات مشفرة تدوم 30 يوماً**:
   - لا تتأثر بإعادة تشغيل السيرفر أو الاستيقاظ السحابي (Cold Starts).

## 🚀 خطوات الرفع والنشر السحابي (على مستودع GitHub جديد)
1. قم بإنشاء مستودع جديد على حسابك في GitHub، مثلاً: `codex-multitenant-system`.
2. ارفع محتويات هذا المجلد (`Upload_To_Cloud_MultiTenant`) إلى المستودع الجديد.
3. على موقع Render.com (أو أي استضافة سحابية):
   - أنشئ **Web Service** جديد.
   - اربطه بالمستودع الجديد `codex-multitenant-system`.
   - حدد **Runtime:** Node.
   - حدد **Build Command:** `npm install`
   - حدد **Start Command:** `node server.js`
